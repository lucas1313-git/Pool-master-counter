                                                      Main Page

                                                      The main page is where every game gets played. Every panel here is collapsed by default with a one-line summary of what's inside — tap the chevron to expand it. The "🎨 Theme" dropdown at the very top switches the whole app's colors and font in one tap and remembers your choice — six dark palettes, two bright/light ones, and two high-contrast pairs (one dark, one light) for maximum legibility.

                                                      • Backup & Restore — 💾 Back up now asks for the file's name (today's is filled in; you can also leave out everyone's contact details), then saves one file with everything: players, games, stats, ratings, saved lists and settings. On a phone or tablet you choose where it goes (Save to Files: iCloud Drive, Google Drive…); on a computer it goes to Downloads. ⬇️ Restore a backup takes a backup file, or a link (to a backup file, or to a Google Drive folder of backups), then asks how: Add to what's here (nothing here is lost) or Replace what's here (what's here is backed up first). Recover Data undoes a reset; Share the last session sends that session to another device. A backup for a shared folder is under ⚙️ More options. (Share Standings is in Publish Daily Report.)
                                                      • Games Rotations — Turn on "Rotate game types automatically" to cycle through a sequence of game rules on their own. Each step in the order is its own rule — game type, target number, and unit (rack/balls/points) — so the same game type can appear twice with different rules (e.g. "8-Ball — 1 rack" then "8-Ball — 3 racks"). The target number and unit are editable right in the list — change either any time without removing and re-adding the step. "Switch every" controls how many games play before advancing. Load Rotation swaps in a saved sequence outright; any new sequence you build is auto-saved as a loadable entry the moment it's set up or played.
                                                      • Current Session — Tournament Setup: Load Setup applies a saved configuration in one tap; Tournament Type is either Race to Wins (set how many wins ends it) or Timed Tournament (set a duration instead); Games Rotation is either Rotate game types automatically or Single Game; Use Fargo rating to balance the race shortens the underdog's target based on the rating gap (❓ for the exact math). Current Game: the game type, the target number, and the unit (rack/balls/points — adjustable independently of the game type's usual default, e.g. One Pocket to "1 rack" instead of "8 balls"), plus the Shot Counter. Reset Current Game (clearing the live score without crediting a win) lives in the All Resets section below; Undo Last Win is the − button on a player's card once their game reaches its target.
                                                      • Players — Add a player by name (auto-capitalized, checked live for a duplicate nickname — the Add button stays disabled until the name is unique). The optional "Starting rating" field lets you seed a brand-new player's rating from a number they've earned elsewhere (another league, another tournament) — it only takes effect for a name that's never been rated on this device before; it's ignored for anyone already tracked. Tap a player's Standby/Playing badge to move them in or out of the current game. The ✕ removes someone from today's roster only — career stats and rating stay on the device; no confirmation if no games have been played yet this session, since there's nothing to lose. Load Player List swaps in players from a saved list (adds anyone missing, never resets what's already there); Export/Import Player Lists use a separate, hand-editable JSON format just for lists.
                                                      • Standings — Live race-to-N progress for teams and individuals this session.
                                                      • Scoreboard — Sits right above the player cards, visible whether Focus Mode is on or off. "Do not record games statistics and players data" stops every save while it's checked — nothing goes into state, career stats, or ratings until you uncheck it; wins still count live on screen for the rest of this browser tab, but none of it survives a reload. Tap + / − on a player's card to track balls/points/racks toward the target. Reaching the target banks a win and starts the next game. Focus Mode hides every other panel down to just the scoreboard — while in it, a small "Players" chevron above the board still lets you flip who's Playing vs Standby without leaving focus; every number on screen also scales up (up to 3x) to stay readable from across the room, shrinking back down on its own once enough players are on screen that the cards get narrower. Whenever Games Rotations is on with 2+ game types, a "Rotation Position" line appears right under the "Now Playing" banner with ◀/▶ buttons - each tap moves the rotation's own games-toward-the-next-switch counter by exactly one game (the same counter a real win advances), so it only actually changes the active game type once enough taps cross a switch-every boundary. No score, win, or ball count is touched - it's purely for correcting the rotation's position by hand if it ever drifts.
                                                      • Recent Games — Every game played today, most recent first. A day runs from 5 a.m. to 5 a.m., so a night that goes past midnight stays one night, even across a race being won and the next one starting fresh; last night’s games that haven’t been saved yet stay here too. Each winner's rating change from that exact game shows beside their badge; the game that completes a race-to-N gets a gold highlight and its own banner line ("🏆 Alice won the Race to 5 session!").
                                                      • Publish Daily Report — A free-text box for anything worth remembering about today's live play; it saves automatically as you type. Copy/Email/Text Report builds a plain-text day report — who played, win/loss and rating movement for each, total games, game types played, a game-by-game breakdown (grouped by matchup — "Luc won 3 games of 8-Ball against Suresh" rather than one line per game) split into earlier-session/current-session, and your notes — ready to paste, email, or send as a text message.
                                                      • All Resets — Every reset button in the app, gathered in one place: Reset Current Game (clears the live score, no win credited), Reset Tournament (offers to save the session first if there are unsaved games, then clears session wins/history and ends any active bracket tournament together), Reset All Players' Official Rating (roster only, back to the default starting rating), and Reset All Player Stats / Reset Player Lists (each backs up first, warns you, then clears — career stats plus the live session, and saved lists, respectively; ratings are never touched). Ending just an in-progress tournament without touching the live session is still on the Tournament page's own Abandon Tournament button.
                                                      • 📺 Stream overlay (OBS, YouTube, Facebook) — A scoreboard to lay over a live stream, on a see-through background: the names, Q-Scores, the score, Race to N, the game, the rack and who breaks. 1) On the device keeping score (the scoreboard opened from the computer's server), ☰ Menu › More › Multi Tables › 🎯 Host This Session. 2) In OBS add a Browser Source: URL http://localhost:4173/overlay.html?layout=lower, width 1920, height 1080 — or ?layout=vertical at 1080 × 1920 for upright 9:16 video. OBS on another computer: the computer's address instead of localhost (e.g. http://192.168.1.20:4173/overlay.html?layout=lower) plus &device= and the app key from ☰ Menu › More › 📱 Paired devices › Show the address. 3) Go live on YouTube or Facebook from OBS as usual. Nothing to tap on the overlay — options go in the address: &theme=emerald-rail (otherwise the scoring device's theme), &lang=french, &break=alternate (otherwise the last rack's winner breaks), &ratings=off, &pos=top. The full guide is docs/stream-overlay.md.

                                                      Ratings show as a small badge next to every player's name throughout the app — an Elo-style number (see the Player Stats section below for details). Every player's name is also a shortcut: tap it (the 📊 icon on the roster row) to open their individual stats page.

                                                      Setup Wizard

                                                      The fastest way to start playing. Five steps, each with its own on-screen explanation:

                                                      • 1. Game type & format — Individual (casual, no fixed target), Race To (asks for a win target), or Tournament Elimination (skips straight to the bracket setup below).
                                                      • 2. Players — Load a saved list and/or add players; each chip has a ✕ to remove someone you don't want in this game.
                                                      • 3. Playing vs Standby — Turn on Playing for everyone in this game (at least two required to continue).
                                                      • 4. Rotation — Plain yes/no: automatically switch game types, or just play one type all session.
                                                      • 5. Review & Start — A summary of every choice; Start applies it all, switches to Focus Mode, and closes the wizard.

                                                      Canceling is always safe — any players added or rotation changes made along the way are already saved, exactly as if you'd used the main page panels directly.

                                                      ⏱️ Only a temporary counter — check it on Step 1 and a "▶️ Start Game Now" button appears; tapping it skips the rest of the wizard entirely and drops you into Quick Counter: Focus Mode with a bare point tally — no game type, no target, no rotation, no win/loss detection, and nothing written to storage (state, career stats, ratings, saved lists — all of it, gone the moment you reload). Each card's name is directly editable, every card has its own remove button, scores can go negative, and an "+ Add Player" field sits at the end of the row. If there's a saved player list, a "📋 Load Player List" row also appears — loading one makes the active players match that list exactly, dropping anyone not on it to standby (their data isn't lost — typing their name back in reactivates them) and adding/activating everyone who is. "↺ Reset All to 0" zeroes every card's tally at once, no confirmation needed. Everything needed to add, rename, remove, load, reset, and count is right there in the scoreboard, nothing else to set up.

                                                      All Players

                                                      Every player who's ever played on this device — including anyone no longer on the roster, and anyone only found in this session's still-unsaved history.

                                                      • Sort by — win percentage, total wins, or name.
                                                      • Show — the time period the stats and graphs cover: Today, 1 Week, 1 Month, 6 Months, 1 Year, or All Time.
                                                      • 📈 See as Graph / 📊 See as Bars — Bars show Games Played/Won/Lost as scaled bars plus a timeline. Graph shows a cumulative line chart instead (see below).
                                                      • 👥 Current Roster Only — Hides everyone not on the live roster without deleting anything; turn it off to see everyone again.

                                                      Each card shows the player's rating badge and, if they've played this period, how much it moved ("▲ +18" or "▼ −9"). In graph view, players on the live roster show their chart immediately; everyone else collapses to a name and a Show Graph button, so the page stays scannable. The graph itself plots cumulative games played/won/lost over time — smoothed curves, a dot at every real data point, a legend where any line can be shown or hidden (Lost starts hidden), and a separate Rating chart underneath tracking that player's rating over the same period (its own scale, since ratings and game counts aren't comparable numbers).

                                                      Tournament

                                                      A knockout bracket — or a round robin — instead of a regular session.

                                                      • Format — Double Elimination: lose once, drop to the losers bracket for a second chance; lose twice and you're out. Single Elimination: lose once and you're out — the faster option, no losers bracket or grand final. Round Robin: no elimination at all — everyone plays everyone else once, and whoever has the most match wins once every match is done is champion (a tie is shared by every player at the top). Swiss: no elimination either, but not every pairing — each round pairs players with a similar win count so far (never a repeat pairing) for a fixed number of rounds sized to the field; most wins at the end is champion (ties share it). Good for a field too big for round robin.
                                                      • Setup — game type, per-match target, race-to per match, and a checklist of who's competing. Seeding is a random draw by default; turn on "Set seeds manually" to rank the field yourself — any seed left blank falls back to the checklist's own order. Round robin's match order is always random, since there's no bracket to seed.
                                                      • Reading the bracket — Winners Bracket, Losers Bracket (double elimination only), and Grand Final render as a horizontal tree with connector lines. The active match is highlighted; eliminated players are struck through; the champion gets a 👑. Round Robin instead shows a live Standings list (ranked by match wins) above the full list of Matches. Swiss shows the same kind of Standings list (with a Buchholz strength-of-schedule figure for reference) above every round played so far, each as its own labeled group of matches.

                                                      Every rack played in a tournament still counts toward career stats, ratings, and the All Players graphs — it isn't a separate pool of data.

                                                      League

                                                      An ongoing, never-ending APA-style handicap points ladder for a fixed group of players — Skill Levels handicap each match's target so a mismatch still plays close. No server: the organizer exports a league file, everyone else imports it to see standings.

                                                      • Setup — create a league (8-Ball or 9-Ball), add members from your known players, and set each member's Skill Level (a suggested value is filled in from their app rating, freely editable).
                                                      • Tables — set how many physical tables are running; each shows up as its own slot in the Tables grid, and a match scored to its target there finishes and updates standings automatically, on its own board, without affecting any other table's live game.
                                                      • Queue Mode — Manual leaves every table's next pairing to the organizer. Per-Table Queue gives each table its own line; Per-Room Queue shares one line across every table. Either way, both players from a finished match rotate to the back of the line rather than dropping out, and a confirm dialog (with a sound) proposes the next pairing the moment a table frees up.
                                                      • Teams — group league members into teams, then assign a team to a table (Per-Table Queue mode) to seed that table's queue with the whole roster in order — a one-tap way to keep a team's players rotating through their table on their own.

                                                      Export League/Import League share a league file between devices — an imported copy is always read-only, even re-imported back onto the organizer's own device.

                                                      Player Stats Page

                                                      Opened by tapping a player's name anywhere in the app.

                                                      • Stats Synopsis — Rating (current number) and "Rating this period" (how much it's moved), Wins, Losses, and Win % for Today, Last 7 Days, Last 30 Days, This Year, or All Time.
                                                      • Head-to-Head — Its own collapsed panel (tap to expand) with a win/loss record against every opponent faced in the selected period; the collapsed summary line lists who they've played without needing to open it.
                                                      • Graph — The same cumulative games chart as All Players, scoped to this one player, plus the standalone Rating chart underneath.
                                                      • This Session (Live) — What they've done in the game currently in progress.
                                                      • Session History — Every past saved session, expandable into the individual games played.
                                                      • Export Stats saves the current live session into permanent history; Reset Stats clears just this player's saved history (their rating is untouched — it lives in its own store and is never reset from here).

                                                      About ratings: every player has an automatic, Elo-style rating (roughly 0–900) inspired by the scale FargoRate publishes — the system behind USA Pool League and most competitive USA leagues. A 100-point gap between two ratings works out to about a 2:1 expected win ratio, doubling every 100 points. New players start at 400, unless a starting rating was given when they were added (see Players, above) — that's a one-time seed for a brand-new name only, not an edit of a rating already being tracked. From there it updates itself after every credited game (main scoreboard or tournament rack) — there's no way to edit an established rating by hand. Both players of a game move by the same amount (a new player's faster speed and a regular's slower one are averaged), team games count too (each side by its average rating), a league match counts once, and a longer game counts more than a single rack: a game of several racks or a Straight Pool game, up to three times as much. It's a from-scratch calculation matched to Fargo's published odds, not a copy of Fargo's own (proprietary, globally-recomputed) algorithm. The rating badge follows a player's name everywhere throughout the app.

                                                      📷 Camera Recognition

                                                      An optional feature: a camera watches the table and automatically selects the correct player on the keypad when they bend over to shoot — either a separate phone mounted over the table, or this tablet's own camera (built-in or USB). It identifies people by clothing and rough body shape, not faces, so it needs a quick one-time "enrollment" per player and a little ongoing upkeep to stay accurate — this section covers all of it.

                                                      • Setup — tap "📷 Set Up Camera" under Players and choose a path: a separate phone (works over your local network only, no internet involved) or this tablet's own camera. Same-device mode needs a secure page load (HTTPS, or localhost) to access the camera at all — the wizard tells you if that's not met yet. Once set up, the camera auto-starts minimized into the Players panel on every future page load — no need to start it by hand again.
                                                      • Calibrating the table — tells the camera exactly where your table's rails are, so it only counts people actually standing at it, not someone walking past or sitting nearby. Tap "Full Screen" on the camera preview, then either tap the 4 corners yourself (most reliable) or try Auto-Detect (faster, but can mis-detect the felt color if lighting or reflections are tricky). Turn on "Show camera debug info" afterward and check the pink outline it draws actually traces your real table — if it doesn't, redo calibration before trusting anything else.
                                                      • Enrollment — each unenrolled player shows an "Enroll" button in the roster; tap it, then have them bend over and shoot a few practice shots. This isn't one-and-done: every time you confirm a point for a player on the keypad, the camera quietly learns what they currently look like too, so a shirt change or different lighting doesn't break recognition on its own — but that only works if the game manager actually selects the correct player on the keypad before confirming each point, ideally every single shot. Tap the "?" beside any enrolled player's icon for the full explanation in plain terms.
                                                      • Scorecard icons — once set up, a camera icon sits above each player's name on the scorecard, its colour saying how the camera knows about them right now: green — in view and recognized by how they look; yellow — someone in view is taken for them, but not for sure (followed along the way they walked, a near match, the camera's best guess); blue — out of view, but the camera has an idea where they are in the room (held at the table, or where it last saw them); light grey — not seen, nothing to go on. A "+" means a fresh sample just got captured for them; a "?" means the camera sees someone bent over it can't confidently name, and this is its best guess — tap that player on the keypad to confirm (this also feeds the camera a strong, human-confirmed sample).
                                                      • "Select player from keypad" banner — appears over the scorecard whenever the camera sees someone shooting it can't identify at all. It clears itself once resolved; tapping the actual shooter on the keypad dismisses it and tells the camera who that was, same effect as the per-player "?" icon above.
                                                      • Tuning settings — Match sensitivity, Consecutive frames, Re-announce after, both Bend angle settings, and Max distance from rail all live under the camera checkbox in Players (same-device) or inside the camera's own Settings tab (either mode). Every one of them has its own "?" explaining what raising or lowering the number actually does, in plain language — open the right one instead of guessing.

                                                      If recognition seems unreliable: turn on "Show camera debug info" and watch the running log under the checkbox — it shows the actual distance numbers behind every miss, not just pass/fail, which is almost always more useful than guessing at a setting to change. Camera placement matters more than any setting: mount it along one of the table's long sides rather than at one end, since that roughly halves the worst-case difference in how large/clear someone looks depending on where they're standing. All of this — calibration, enrollment, and settings — persists across restarts and travels with Export All Data / Import Data, same as everything else in the app.

                                                                      Tournament format

                                                                      Double Elimination Tournament Format Winners & Losers Brackets: lose once, drop to the losers bracket for a second chance; lose twice and you're out. Fairer than single elimination since one bad game doesn't end your tournament — but it takes longer to play out. Single Elimination Tournament Format Only winners advance: lose once and you're out. The fastest format — best for a quick knockout when there isn't time for a longer event. Round Robin Tournament Format No elimination — every player faces every other player once. Whoever has the most match wins when it's all done is champion (ties share the win). Best for a casual group where everyone should get equal games in. Swiss Tournament Format A proper non-elimination format where everyone plays a fixed number of rounds (e.g., 4 or 5), drawn each time against opponents with identical win-loss records. Once those scheduled rounds wrap up, whoever has bagged the most match victories takes the crown!
